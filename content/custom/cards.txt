# ============================================================================
# YUGS CUSTOM CARDS
# ============================================================================
# Every card starts with its ID number in square brackets: [1900000000]
#   - The first custom card is 1900000000, the next 1900000001, and so on.
#   - Never change a card's ID once players own it (the ID is how the game remembers it).
#   - Artwork:  content/custom/pics/<ID>.jpg      e.g. pics/1900000000.jpg (or .png / .webp)
#   - Effect:   content/custom/scripts/c<ID>.lua  e.g. scripts/c1900000000.lua (same naming as EDOPro)
#
# Fields (write "Field: value", one per line):
#   Name:        the card name players see (must be unique)
#   Card type:   e.g. Normal Monster, Effect Monster, Effect Monster Tuner,
#                Flip Effect Monster, Ritual Effect Monster, Fusion Monster,
#                Fusion Effect Monster, Synchro Effect Monster, Xyz Effect Monster,
#                Link Effect Monster, Pendulum Effect Monster,
#                Spell, Quick-Play Spell, Continuous Spell, Equip Spell,
#                Field Spell, Ritual Spell, Trap, Continuous Trap, Counter Trap
#   Attribute:   EARTH, WATER, FIRE, WIND, LIGHT, DARK, DIVINE   (monsters)
#   Type:        Warrior, Spellcaster, Dragon, Machine, ...       (monsters)
#   Level:       1-12   (Xyz monsters use "Rank:", Link monsters use
#                "Link Rating:" and "Link Arrows: Bottom-Left, Top, ...")
#   Scale:       Pendulum Scale (Pendulum monsters only)
#   ATK / DEF:   numbers, or ? for "?"
#   Text:        the card text. Long texts can continue on the next lines
#                if those lines start with spaces.
#   Prompt 1..16: short questions shown in the duel, used by the script as
#                aux.Stringid(id,0) for Prompt 1, aux.Stringid(id,1) for Prompt 2...
#
# Lines starting with # are comments. Restart the server after editing this file.
# (Editing a script file doesn't need a restart: it applies to the next duel.)
# ============================================================================
